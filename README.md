# Tilt Snake 🐍

A tiny Snake game you play by tilting your phone — no touch controls, no build tools, no dependencies.

Tilt left/right to steer horizontally, tilt forward/back to steer vertically. Eat the red dots, grow longer, and don't run into yourself. On desktop, arrow keys / WASD work too.

**Features**
- 📱 Device-tilt steering with a dead zone + smoothing (no twitchy turns)
- 🎮 Keyboard fallback (arrows / WASD) and Space to pause
- 💾 Best score saved locally
- 📦 One `index.html` — just open it or drop it on GitHub Pages

**Play:** open `index.html`, or enable GitHub Pages for this repo.
